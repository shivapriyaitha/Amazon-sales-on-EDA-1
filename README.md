#  Data Analysis Project

## 📌 Project Overview

This project performs **Exploratory Data Analysis (EDA)** on a sales dataset using Python. The main purpose is to clean, analyze, and visualize the data to identify important patterns, relationships, and trends.

The project uses **Pandas, Matplotlib, and Seaborn** for data processing and visualization.

## 🎯 Objectives

* Load and understand the sales dataset.
* Perform data cleaning and preprocessing.
* Analyze numerical and categorical variables.
* Identify sales patterns and trends.
* Study relationships between different variables.
* Create visualizations to communicate important findings.
* Generate useful insights from the dataset.

## 🛠️ Technologies Used

* **Python**
* **Pandas** – Data manipulation and analysis
* **NumPy** – Numerical operations
* **Matplotlib** – Data visualization
* **Seaborn** – Statistical visualization
* **Jupyter Notebook** – Development environment

## 📊 Analysis Performed

The project includes the following analysis:

### 1. Data Loading

The dataset is imported using Pandas and examined to understand its structure, columns, and data types.

### 2. Data Cleaning

The dataset is checked for:

* Missing values
* Duplicate records
* Incorrect data types
* Inconsistent values

### 3. Exploratory Analysis

Statistical summaries and distributions are analyzed to understand the dataset.

### 4. Data Visualization

Different charts are created, including:

* **Heatmap** – To examine correlations between numerical variables.
* **Boxplots** – To identify the distribution and outliers of sales/revenue values.
* **Bar Charts** – To compare sales across different categories.
* **Category Analysis** – To compare performance across different product or customer categories.

## 📈 Key Insights

The analysis helps identify:

* Differences in sales performance between categories.
* Distribution of sales and revenue values.
* Potential outliers in the dataset.
* Relationships between numerical variables.
* Categories or segments contributing more to overall sales.
* Patterns that can support data-driven decision-making.
